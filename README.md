# Agent-Auto-ERP-Email-Sender-

Agent-Auto-ERP-Email-Sender is an automated system that monitors your ERP data and sends emails based on specific keywords. For example, if a record is marked as "overdue," it automatically sends an email to the respective supplier via Outlook. When the supplier replies, the system analyzes the response and updates the ERP data accordingly. This ensures timely communication, reduces manual work, and keeps your data always up to date.
